Website Prototypes and Landing Page Mockups

  • Figma’s free education option — Prototyping software that has a free education option.
  • Canva Prototypes — Canva has come a long way since we first found them years ago. They now have pretty Canva mobile prototype templates. They’re now creating interactivity options as well.
  • Sketch — Another popular prototyping tool. While not free, it’s pretty affordable.
  • Wix.com — Very easy way to make a free website (mockup). Technically, you’re actually building a website, but they have a WYSIWYG platform, meaning that you can click on templates and swap out items without knowing code. This free version has ads, and it doesn’t have robust functionality features. But it does have a way to lay out a basic, interactive website design very quickly.
  • Adobe Express — Rutgers students get free Adobe products, so this is an option all of you will have access to.
  • Google Slides — Because of the dimensions, this would be better suited for those designing a website instead of mobile. With this option, you won’t have the ability for the prototype to be fully interactive and will need to manually change slides when the user points to a button.

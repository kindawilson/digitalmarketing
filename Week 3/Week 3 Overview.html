Website, UX, and UI

This module will be covering the website, including elements of the User eXperience (UX) and User Interface (UI).

When we talk about the “website / UX UI” part of digital marketing, we’re referring to the way that we can design digital elements of the website, including the landing page or homepage. But it really goes beyond that. Once you learn the psychology behind how consumers process design elements, you can also use that knowledge to help design ads and other digital elements as well. It really does affect the entire consumer experience.

This module will cover how humans process information, the design strategies we can use, and page templates that we can apply to effectively market to our customers.

# Vanderbilt Digital Marketing Project Instructions

## Interactive iframe header standard

For every new or modified Vanderbilt interactive iframe, reuse the established integrated header component. Do not recreate, approximate, simplify, or restyle it.

Canonical reference: `Week 2/Brand Identity Workshop.html` in this project. Equivalent approved implementations appear throughout the completed Week 2–4 interactive files.

Before delivery, compare the iframe header against the canonical reference and verify all of the following:

- The visible activity title uses Century Gothic (with the approved fallback stack), Vanderbilt teal, 700 weight, uppercase treatment, approved responsive sizing, line height, and letter spacing.
- The eyebrow text is exactly `Interactive Learning` and uses the approved Century Gothic styling.
- The subtitle describes the current interaction, uses 15px bold Lato at full width and 14px at the compact breakpoint, and spans the header width below the badge/title row.
- The header has the 6px Vanderbilt-gold top rule, 12px rounded top corners, light border, approved gradient, spacing, and responsive one-column treatment at 700px or below.
- The `Try This` badge uses the approved teal/gold colors, dimensions, border, rounded corners, typography, shadow, and `integratedBadgePulse` animation.
- The badge contains the approved SVG pointer, not a text arrow, and the pointer uses the `integratedCursorTap` animation.
- A `prefers-reduced-motion: reduce` rule disables both badge and pointer animations.
- The header is visually checked at full width, 600px, and a smaller mobile width. Confirm no clipping or horizontal overflow.

Do not treat an iframe created later as the template merely because it looks similar. Compare it with the canonical reference above before reusing its header.
